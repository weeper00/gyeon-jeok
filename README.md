# 견적 원장 v1.0.0

견적가와 실행가를 함께 관리하는 인테리어 견적 앱. 데이터는 사용하는 기기에만 저장되며 어디로도 전송되지 않는다.

## 배포 (GitHub Pages)

1. 새 저장소를 Public으로 만든다.
2. 이 폴더의 파일 7개를 저장소 맨 위에 올린다 (폴더째 올리지 않는다).
3. Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소 이름>/` 주소가 생긴다.

앱을 고쳐 다시 올릴 때는 `sw.js`의 `CACHE` 값(`gyeonjeok-v1.0.0`)을 새 버전으로 바꾼다. 바꾸지 않으면 설치된 앱에 늦게 반영될 수 있다.

## 갤럭시 설치

1. 카톡으로 받은 주소를 누른다.
2. 화면 위에 노란 안내가 뜨면 'Chrome으로 열기'를 누른다 (또는 메뉴 ⋮ → 다른 브라우저로 열기).
3. Chrome에서 상단 '앱 설치' 버튼, 또는 메뉴 ⋮ → '홈 화면에 추가'.

## 사용

- 처음 실행: '예시 견적으로 둘러보기' 또는 '바로 시작하기'.
- 설정·백업 탭에서 사업자 정보(상호, 대표자, 연락처)를 입력하면 견적서에 표시된다.
- 단가표의 예시 단가는 실제 시세가 아니다. 본인 단가로 바꿔 쓴다.
- 고객에게는 '고객용 견적서' 탭만 보여준다. 실행가와 마진은 그 화면과 PDF에 나오지 않는다.
- PDF: 고객용 견적서 → '인쇄 / PDF 저장' → 프린터 'PDF로 저장'.
- 백업: 일주일에 한 번 설정·백업 → '공유' → 구글드라이브 또는 카톡 나와의 채팅. 앱을 지우면 데이터도 지워진다.
- 기기 이동: 기존 기기에서 '파일로 저장' → 새 기기에서 '파일 불러오기'.
